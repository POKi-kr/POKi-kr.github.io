일본어 단어 읽기 프로그램 

단어장 추가기능 txt파일 '일본어|요미가나|한글뜻|품사'

단어장 체크기능


words 폴더를 저장소 맨 위에 만들고, 그 안에 txt 두 개와 index.json을 넣어 주세요. N5 단어가 694개가 아니라 693개인 이유는, 예전 목록에서 읽기가 같은 중복 단어 하나가 합쳐졌기 때문이에요.

동작 방식

처음 열 때: N5, N4 탭이 자동으로 생겨요. 한 번 읽어 온 뒤에는 브라우저에 저장되어서 다시 읽어 오지 않아요.
삭제: 탭 오른쪽 ×를 두 번 누르면 지워져요. 지운 기본 탭은 다시 열어도 되살아나지 않아요.
복원: 설정 창의 "기본 단어 복원" 버튼을 누르면 지운 기본 탭이 다시 생겨요.
내가 추가한 탭: 지금처럼 txt 파일로 추가해서 같이 쓸 수 있어요.

기본 파일을 더 늘리려면
words 폴더에 txt 파일을 넣고, index.json에 {"file": "파일이름.txt", "name": "탭이름"} 줄을 추가하면 돼요. 코드는 고치지 않아도 돼요.

주의할 점

이미 쓰고 계신 기록(외운 단어 등)이 있으면, 같은 주소와 같은 브라우저에서는 그대로 남아 있어요. 다만 이전 버전에서 만든 N5, N4 탭은 이름이 다른 별개 탭으로 취급되어, 새 N5, N4 탭이 하나 더 생길 수 있어요. 그때는 예전 탭을 × 로 지우면 돼요.
claude.ai에 게시한 링크에도 같은 코드가 들어갔지만, 거기서는 다른 파일을 읽을 수 없어서 기본 단어가 나오지 않아요. 기본 단어는 GitHub Pages에서만 보여요.
